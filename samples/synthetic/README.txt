GeoVision Pro synthetic sample data (generated by SyntheticSurveyGenerator).
synthetic_stack.sgy  : post-stack time volume, IBM float, inline/crossline at bytes 189/193, coordinates at 181/185 (scalar -100).
synthetic_gathers.sgy: NMO-uncorrected CMP gathers, offsets at bytes 37-40 (m).
GV-*.las             : wells (GR, RHOB, NPHI, DT, DTS, RT) consistent with the seismic model; KB = 25 m, SRD = MSL.
GV-*_checkshot.csv   : MD, TVDSS (m), TWT (ms).
*.xyz                : true horizons (X Y INLINE CROSSLINE TWT_ms).
fault_F1_sticks.txt  : fault sticks (X Y INLINE CROSSLINE TWT_ms STICK).
rms_velocity_center.txt: RMS velocity function t(s):v(m/s) at the anticline crest.
